# Ugly Ads Generator

A skill for generating PNG ads in the course-marketer aesthetic — the design philosophy behind every high-converting "FREE [thing] / THAT DOESN'T SUCK" ad you've ever scrolled past. The premise: in a feed full of polished brand content, an ad that's stark, audience-targeted, and built around one enormous hook word reads as confident and conversion-focused.

There is **one template** in this skill: `course-marketer`. Every ad generated by this skill uses it.

## When to use this skill

Trigger this skill when the user wants:

- A social media ad or organic post (FB, IG)
- A promo graphic for a course, training, lead magnet, coaching offer, or service
- A "stop the scroll" graphic for a specific audience
- Anything where the value prop is the transformation, not a SKU

Do **not** trigger this skill for: polished brand work, logos, infographics, product photography, or anything where the user explicitly wants "clean," "minimal," or "professional" in the corporate sense.

## The "ugly works" principles

Before generating anything, internalize what makes a course-marketer ad actually convert:

1. **The qualifier pill identifies the audience immediately.** Scrolling past, only the target stops. The rest of the feed self-filters out.
2. **One enormous hook word does 80% of the work.** "FREE," "STOP," "WARNING," "HOW," "NEW" — one word, massive, all caps, white-on-color. Impossible to miss at thumbnail size.
3. **The offer stack is tight.** 2-3 short lines describing what the offer is, stacked centered, tight line height — reads as one block.
4. **The punchline qualifier signals voice.** A small last line that breaks the formal pitch ("THAT DOESN'T SUCK", "WITHOUT THE BS", "NO FLUFF"). Reads as a real person.
5. **The gradient is the only "polish" element.** Everything else is deliberately stark — flat type, no shadows, no decorative shapes. The gradient does all the visual work.

If the user's request would push the design away from these principles (more than one hook word, decorative shapes, etc.), gently steer back. The whole point of this aesthetic is the discipline.

## The workflow

This is a **two-stage** workflow. Copy first, then design. **Do not skip ahead to rendering** — the copy needs explicit approval first.

### Stage 1 — Copy

#### Step 1.1: Gather the brief

The user will give you either raw copy, a topic, or a one-liner. Get what you need to write good copy:

- **Who is this for?** (The audience that goes in the qualifier pill)
- **What's the offer?** (The thing being given away or sold — free training, free session, lead magnet, etc.)
- **What's the angle / why now?** (The transformation, the pain point, the timing)
- **CTA?** ("Click Learn More," "DM SOLD," "Book a call," etc. — usually doesn't appear *on* the ad itself for this template, but informs voice)

If the user gave you a long copy doc (like a full FB ad post), pull the audience + offer + angle out of it yourself. Don't ask them to re-explain what's already in front of you.

If the user gave you just a topic, ask 1-2 targeted questions before writing.

#### Step 1.2: Write 5 copy variations

Write **exactly 5** distinct copy variations. Each variation must have all four fields:

1. **Qualifier pill** (audience, all caps, ending with a colon — e.g., `SOCCER PARENTS:`)
2. **Hook word** (one word, all caps — FREE / NEW / STOP / HOW / WARNING / TIRED / READY)
3. **Offer stack** (2-3 short lines describing the offer, all caps)
4. **Punchline qualifier** (one short line that breaks the formal pitch — can be all caps or sentence case)

Make the 5 variations **distinctly different** — different hooks, different angles, different audiences if relevant. Don't write five slight rewrites of the same idea.

Present them as a numbered list in chat. Example format:

```
1.
   Pill:      SOCCER PARENTS:
   Hook:      FREE
   Offer:     1:1 GAMEPLAN
              SESSION
   Punchline: WHERE YOUR ATHLETE ACTUALLY STANDS

2.
   Pill:      TIRED OF THE BENCH?
   Hook:      STOP
   Offer:     SETTLING FOR
              TEAM PRACTICE
   Punchline: TALENT ALONE WON'T DO IT

...
```

After the list, ask: "Which one do you want to move on with? You can pick one, pick a hybrid, or have me edit one."

#### Step 1.3: Wait for copy approval

**Do not render anything yet.** Wait until the user picks (or edits) one of the variations. They might say:

- "Go with #2"
- "Use #1 but change the punchline to X"
- "Combine #3's pill with #4's hook"

Lock in one final copy block (pill + hook + offer + punchline) before continuing.

### Stage 2 — Design

#### Step 2.1: Ask how many design variants

Ask: "How many design variants do you want?" Default to 3 if they don't have a preference. They can ask for 1-10.

Each variant uses the same locked-in copy but varies the **gradient color pair** (and optionally slight type sizing / spacing). The five built-in gradient pairs are:

- Purple `#7C3AED` → Orange `#F97316` (energetic, modern)
- Deep blue `#1E40AF` → Magenta `#EC4899` (tech / SaaS)
- Teal `#0D9488` → Lime `#84CC16` (wellness / fitness / sports)
- Crimson `#B91C1C` → Amber `#D97706` (urgency / financial)
- Indigo `#4338CA` → Hot pink `#DB2777` (creative / agency)

If the user asks for more variants than there are gradients (more than 5), reuse gradient pairs but vary sizing / layout subtly.

If the user has a brand color preference, use it — but still as a two-color diagonal gradient, not a flat fill.

#### Step 2.2: Read the template rules

Read `templates/course-marketer/template.md` before generating. It encodes the typography, layout, spacing, and rules that make this aesthetic work. The template rules are the source of truth; this SKILL.md just describes the workflow.

#### Step 2.3: Render the PNGs

Use `scripts/render.py` with a JSON config per variant. See `references/rendering.md` for the config schema and layer types.

For each variant:
1. Build the config dict (gradient pair, copy fields, sizes).
2. Call `python scripts/render.py --config <config.json> --output <output.png>`.
3. Save to `ugly-ads-output/<timestamp>/variant-{n}.png` by default, or wherever the user specified.

After all variants render, report the file paths and briefly describe what differs between them ("Variant 1 uses the teal→lime gradient for a sports feel, Variant 2 uses crimson→amber for urgency").

#### Step 2.4: Iterate

The first batch is a draft. Ask: "Which gradient is closest? Want a different color pair, different sizing, or are we done?" Then re-render only what needs changing.

## What this skill does NOT do

- **It does not render before copy is approved.** Always do Stage 1 first. Always.
- **It does not generate other aesthetics.** No clickbait popups, no used-car-lot starbursts, no GeoCities. Just course-marketer.
- **It does not fabricate testimonials, credentials, or stats.** Anything in the copy that reads as a fact (years coaching, number of students, etc.) must come from the user.
- **It does not produce ads designed to deceive** (fake system alerts, fake account warnings, etc.).
